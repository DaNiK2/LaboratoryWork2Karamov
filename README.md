# Лабораторная работа: Демонстрация и устранение веб-уязвимостей (OWASP Top 10)

Данный проект представляет собой учебный веб-сервис на языке Python (Flask), демонстрирующий реализацию типичных уязвимостей веб-приложений, сценарии их автоматической эксплуатации и методику безопасного исправления (патчинга).

## Описание проекта и реализованные уязвимости

Сервис включает две критические уязвимости из классификации **OWASP Top 10**:

1. **SQL Injection (A03:2021 – Injection)**
   * **Эндпоинт:** `POST /login`
   * **Проблема:** Небезопасная подстановка пользовательского ввода напрямую в SQL-запрос через форматирование строк (f-строки) без предварительной валидации и параметризации.
   * **Последствия:** Обход аутентификации (вход под учетной записью администратора без знания пароля) с использованием пейлоада `' OR 1=1 --`.

2. **Path Traversal / Local File Inclusion (A01:2021 – Broken Access Control)**
   * **Эндпоинт:** `GET /view?file=<имя_файла>`
   * **Проблема:** Небезопасное конструирование пути к файлу с использованием `os.path.join` без проверки выхода за границы разрешенной рабочей директории (`reports/`).
   * **Последствия:** Несанкционированное чтение файлов операционной системы и исходного кода приложения (например, `?file=../app.py` или `?file=../../../../etc/passwd`).
